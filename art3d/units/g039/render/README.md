# g039 Ghast（恶鬼）3D 重制精灵

从 `../g039.glb`（已绑骨模型）在 Blender 5.2 渲染出游戏需要的全部画面，并打包成游戏格式。

## 产出

| 路径 | 内容 |
| --- | --- |
| `xpf/` | 可直接替换进 tc2.dat 的精灵档：`g039st/mo/at/da.xpf`（本体）、`g039stb/mob/atb.xpf`（光剑光晕，叠加层）、`g039sts/mos/ats/das.xpf`（影子遮罩） |
| `tc2_g039.dat` | 以 `out/tc/tc2.dat` 为底、换入上述 xpf 的完整 tc2.dat（`pack_g039.py --dat` 产生） |
| `frames/<动作>/<body|glow|shadow>/dD_fFF.png` | Blender 原始渲染，D = 方向 0–7，FF = 帧号 |
| `preview/cmp_*.png` | 原版（左）与新版（右）对照，每行一个方向 |
| `orig_xpf/` | 原版 g039 精灵（写回时的模板，含档头动画资料） |
| `g039_pipeline.py` | Blender 端：建场景、动作、渲染（在 Blender 里 `exec(open(路径).read())`） |
| `pack_g039.py` | 打包：渲染 → .xpf（`python3 pack_g039.py [--dat]`） |
| `g039_sprites.blend` | 渲染场景的副本 |

## 规格（对齐原版）

- 画布与枢轴：st / mo / da 为 179×179，at 为 177×178，枢轴 (89,109) 为脚底中心；影子层画布沿用原档（ats 190×178、das 235×177）。
- 正交相机，俯角 55°，每米约 40.7 px；8 方向，方向 0 朝画面右方、顺时针，帧序为「帧号 × 8 + 方向」。
- 帧数：st 12、mo 12、at 14（各 8 方向），da 1（单方向残骸）。脚印层 `mop` 沿用原版。
- 本体与光晕以 4 倍解析度渲染（`frames/` 里是 716 px 左右的大图），打包时以 Lanczos 缩回原尺寸、锐化并拉开明暗对比；影子以原尺寸渲染。
- 光剑光晕 `b` 层是叠加（additive）显示：黑色等于不改变画面，所以渲染时只留发光胶囊。
- 影子：用几何节点把变形后的模型沿光线方向压到地面，以 EEVEE 渲成遮罩（Cycles 影子会让 Blender 当掉，已弃用）；光线方向依原版影子实测，落向画面右后方。

## 动作

- st 待机：0–3 帧持剑，4–8 帧把剑转向前方再收回（照原版的花式），9–11 帧回位。
- mo 移动：前倾跑步，剑压低拖在身侧。
- at 攻击：举剑蓄力 → 由前上方斜劈到前下方 → 收回，伴随前冲。
- da 死亡：仰倒在地。

## 换进游戏

1. 先备份游戏目录的 `tc2.dat`。
2. 把 `tc2_g039.dat` 改名为 `tc2.dat` 覆盖进游戏目录；或用 `tools/sgdat_add.py 游戏的tc2.dat 新tc2.dat xpf/*.xpf` 以游戏现有版本为底重新打包。
