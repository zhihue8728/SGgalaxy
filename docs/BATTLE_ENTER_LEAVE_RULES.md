## 0. 名詞

| 名詞 | 定義 |
|---|---|
| 戰場 | 一個有進行中戰鬥的省份地圖（30 分鐘上限）。洞穴、獵場、模擬中心不在本文件範圍。 |
| 防守方 | 省份擁有國及其同盟。無主省（外星怪）沒有防守方玩家。 |
| 進攻方 | 戰場上不屬於防守方的一方（打無主省也算進攻方）。 |
| 己方土地 | 自己國家、同盟國擁有的省。**無主省不算**己方土地，但撤退時可以退進去（見 3.4）。 |
| 場上單位 | 已進場、還活著、沒撤走的單位。後備單位（沒進場）不算。 |
| 隊友 | 同陣營（同國或同盟）在同一戰場上、還有場上單位的玩家，以及同陣營的 NPC 單位。 |

## 1. 地盤規則（總原則）

1. **沒有戰鬥時，任何玩家、NPC 都只能待在己方土地或首都。** 待在敵國省或無主省、那裡沒有進行中的戰鬥、超過 15 秒 → 強制移出（去向見 3.4）。【待部署】`world.evict_sweep`、`npc_world.npc_tick`
2. 戰鬥中的戰場不受第 1 條限制。
3. NPC 行軍途中「路過」別國省份不算違規。【待確認：是否也要禁止】

## 2. 開戰與進入戰場

### 2.1 開戰
| 規則 | 狀態 |
|---|---|
| 玩家走進**敵國省或無主省** = 開戰（沒有戰鬥就建立，有就加入）。 | 已上線 |
| **NPC 進攻**到達目標省 = 開戰，規則與玩家相同（真實戰鬥，沒有玩家在場時由伺服器模擬）。 | 已上線 |
| **開戰時，站在該省地圖上的所有玩家（城鎮模式、不在戰鬥中）立即被拉進這場戰鬥**，切成戰鬥模式、留在原位置，依自己陣營當防守方或進攻方；聊天提示「你所在的省份開戰了，你已進入戰鬥」。NPC 開戰與玩家開戰都適用。 | 待部署（`battle_maps.pull_into_battle`） |
| **進攻通知**：防守方的線上玩家（不在這場戰鬥裡的）收到聊天系統訊息一行（紅橙色）：「XX省遭到〇〇（玩家名或國名）的進攻！在戰略地圖上右鍵點該省即可前往防守。」依玩家語言與編碼（gbk / big5）送出。玩家進攻與 NPC 進攻都會發。**不可用 0x31**：0x31 是 StarCenter（太空中心）視窗的訊息，客戶端會切到太空中心畫面（20:31 使用者回報，戰場中被切走）。同理「戰場指揮官拒絕加入」「戰鬥中不能傳送回首都」「免費傳送用完」也改成聊天訊息；0x31 只留在 StarCenter 視窗內使用。 | 待部署（`battle_maps.attack_notice`、`notify_defenders`） |

### 2.2 誰可以進、從哪裡進
| 規則 | 狀態 |
|---|---|
| 只能從**相鄰省**走星門進入（不相鄰的換圖請求一律拒絕、留在原地）。 | 已上線 |
| 進入己方省份：沒有戰鬥是城鎮模式；有戰鬥（含被襲擊）則以防守方身分進入戰鬥模式。 | 已上線 |
| 出現位置：**你走來的那個省的星門**；不是從相鄰省來的（例如從大地圖遠端加入），則用通往己方土地、離首都最近的星門。**絕不從面向敵國的星門進場。** | 已上線 |
| 加入進攻方需要戰場指揮官（軍階最高者）同意；Ctrl+F7：全部允許 / 全部拒絕 / 每次詢問（20 秒沒回應視為同意）。加入防守方不需要同意。 | 已上線 |
| 剛離開同一戰場要等 30 秒才能再進（`REJOIN_WAIT`）。 | 已上線 |
| 觀戰：不帶單位、不結算，結束後回首都。 | 已上線 |
| 模擬中心的模擬戰進行中，該省不能真打，反之亦然。 | 已上線 |

### 2.3 帶什麼單位進場
- 部署視窗選定的隊伍，人數上限 = 戰術 ÷ 20 + 6；其餘留後備。
- 同一戰場再次進場的單位一律換新 uid（避免客戶端「雙胞胎」）。
- **F7 = 部署視窗**：從「沒在場上、還活著」的單位中挑選，按 OK 進場（可換兵種）。距上次撤退或進場至少 20 秒（`REDEPLOY_WAIT` / `REINFORCE_COOLDOWN`），提早按 OK 會提示剩餘秒數、時間到自動進場。

### 2.4 NPC 進場
- NPC 一律**行軍過來**，從它來的方向的星門進場；已在省內的守軍幾秒後從星門進場。
- 有主省被攻擊時該國空閒 NPC 指揮官來防守；全部在休息時抽最強的最多 2 位當緊急守軍。
- 戰鬥中友軍發現敵人時，附近空閒的 NPC 會去支援。【待部署】
- 戰鬥進行中進場的 NPC 部隊一律 0x50 延遲進場（見第 8 節）。【待部署】

## 3. 脫離戰場

### 3.1 玩家的離場方式

| 方式 | 觸發 | 撤走哪些單位 | 要不要確認 | 結算畫面 | 狀態 |
|---|---|---|---|---|---|
| **A. 單位走到星門** | 單位踩進出口星門格子 | **只有那一隻** | **要**：客戶端原生確認框，按 OK 才撤走那一隻；取消則留在場上 | 沒有（最後一隻撤走見 3.2） | 待部署 |
| **B. RETREAT 按鈕** | 選單 RETREAT / Ctrl+F11 | **全部** | **不用** | 有（撤退） | 已上線 |
| **C. 斷線** | 連線中斷 | 全部 | — | 沒有 | 已上線 |

A 的機制（逆向確認，不需要客戶端補丁）：
- 單位踩進星門 → 客戶端 `004d17c0` 開確認框（對話框種類 5，`00402eb0`，記著單位 uid 與目的地）→ OK（`00403130`）→ 該單位 `004da400` → `004e1990` 送 0x2f，**只送那一隻**。
- 不跳框的唯一情況：按過「走向撤退」（`004a5270` 設 `main+0x29bf4 = 1`，所有單位自動走向星門直接撤），進入新地圖時清回 0。
- 伺服器收到 0x2f = 玩家已確認，立即撤走該單位（`GATE_CLIENT_CONFIRMS = True`）。
- 伺服器的「星門卡點補救」會繞過玩家確認，已關閉（`GATE_ASSIST_ON = False`）。副作用：卡在星門旁、沒踩到格子的單位不會跳框，要移到星門上。
- 不要再在伺服器加「收到 0x2f 再問一次」（14:35 犯過，會把玩家的 OK 擋掉）。

其他：
- 通往**敵國省份**的星門不能撤退（提示改走通往己方、同盟或中立省份的星門）；四周全是敵國時例外，直接回首都。【已上線】
- 單位死亡後客戶端會補送一次 0x2f，伺服器忽略。【已上線】
- 撤退不算勝敗、不佔領；傷害經驗照算。
- 指揮官整隊撤退的那一刻就退出戰場（單位從所有客戶端移除、交出指揮權），不等 5 秒結算畫面。【待部署】

### 3.3 戰鬥結束（勝負）

| 一方 | 勝利條件 |
|---|---|
| 進攻方 | 佔領**全部 POC**（殺光敵人不夠；沒有 POC 的伏擊戰才是殲滅即勝）。 |
| 防守方 | 進攻方場上沒有任何單位、且沒有人正在等著重新進場；或 30 分鐘到時 POC 過半（平手給防守方）。 |
| 第三方 | 佔住**全部 POC** 才算勝（NPC 進攻戰）。只是在場、不屬於進攻方，不算勝、不佔領。【待部署】 |

結束時每個成員收到結算畫面（0x25），5 秒後依 3.4 離場。

### 3.4 離場後去哪裡
依序取第一個成立的：
1. 戰鬥勝利、且這個省現在屬於己方 → **留在原省**。
2. **所有單位都死了** → **直接回首都**。
3. 還有活著的單位 → **退一格，往首都方向**：相鄰省中挑己方、同盟或無主的省，取離首都最近的，從面向原省的星門出現。
4. 相鄰省全是敵國 → **直接回首都**。

撤退、戰敗、省被佔領後被移出都用同一套。NPC 被移出時周邊沒有可退的省也直接回首都，不再穿過敵國走回去。【待部署】`battle_flow.capital_fallback`、`retreat_target`、`npc_world.npc_release`

### 3.5 NPC 離場
- NPC **不會因為血量低而撤退**（認輸機制關閉）；只有全滅、時間到、被換下（不適合這場的單位走回星門離場）才離開。
- 戰鬥結束、省份不屬於它那一方時依第 1 節移出。

## 4. NPC 在戰場上的行為（與進出有關）
- 防守方 NPC 知道自己是防守方：受傷後主動索敵、報復攻擊者；沒看到敵人時去最後看到的位置搜索。【待部署】
- 射程不超過自己的視野（看不到不能開火），伺服器用真實視野判定。【待部署】

### 4.1 NPC 回應求援（玩家在戰鬥中喊「支援」等，或 NPC 自己告急）【待部署】`npc_world.npc_sos_answer`
- **人數**：每次隨機 1–3 位。
- **從哪來**：首都裡空閒的 NPC、走在回家路上的 NPC（從半路出發），以及在附近省份巡邏／駐守、那裡沒在打仗的 NPC（離開崗位，從所在省出發）。近的優先，但有隨機，不會每次同一批。最遠 `NPC_ASSIST_STEPS` 個省。
- **到達時間**：每省 40 秒 × 0.85–1.3 ＋ 0–25 秒準備；聊天報的秒數就是實際到達時間。
- **帶什麼兵**：第一位帶最需要的剋制兵種；其他人一半機會帶另一種有效兵種、四分之一帶同一種、四分之一用原本部隊；換裝數量隨機。
- **回話**：6 種說法隨機（含「我離XX不遠」「撐住，我過去」等）。
- 尚未隨機化：「發現敵軍正向某省推進」「我們幾人進攻某省」兩種 NPC 主動喊話仍是固定句子。

### 4.2 戰鬥中用格子跟 NPC 隊友溝通（2026-10-25 20:16）【待部署】`npc_battle.npc_battle_hear_cell`、`npc_scout_reports`、`npc_spot_reports`
格子 = 小地圖 5×5：A–E 左到右、1–5 上到下。玩家在同盟或戰場頻道打字即可。

**玩家 → NPC**（同戰場、同陣營的 NPC 小隊）：
| 說法（例） | NPC 怎麼做 | 回話 |
|---|---|---|
| 侦察 D2／偵察／scout D2 | 最快的一個小隊移動到 D2；到了（或 45 秒後）回報：「D2侦察完毕：敌人约 N 个，其中飞机 x，自走炮 y」或「没看到敌人」；小隊全滅則「失去联络」 | 「收到，我去D2看看」等 3 種說法 |
| E3有飞机／空军／air E3 | 最近的最多 2 個有防空武器的小隊到 E3 交戰；沒有防空則喊「谁能打E3的飞机？」 | 3 種說法 |
| A2有敌人／发现敌人 A2 | 最近的最多 2 個小隊到 A2 交戰 | 3 種說法 |
| 救 C3／支援 C3 | 最近的最多 3 個小隊到 C3；**同時**照第 4.1 節叫戰場外的 NPC 來支援 | 3 種說法 |
| 佔點／集合／打 B3／守 B3 | （原有）搶點、向玩家靠攏、到格子交戰、守住格子 | — |

**NPC → 玩家**（NPC 單位附近 700 px 內看到的）：敵方自走砲、隱形單位、地雷（原有），新增：
- 「E3 有敌方飞机（名稱），我的防空过去了／谁有防空？」——並派最近的防空小隊。
- 「A2 发现敌人约 N 个，正在交战」；同一格己方單位比敵人少時改喊「A2 敌人很多（约 N 个），我们人少，请求支援！」（同一格 4 個以上敵方地面單位才報）。
- 同一格同一種事 90 秒內不重報，同一種事 45 秒內同陣營只說一次。

**多人／多客戶端規則**：
- 指令進入**戰場共用的大腦**（每個陣營一個），任何一位同陣營玩家下的都有效；NPC 的移動是一般 NPC 指令，照第 8 節送給戰場上每個客戶端、同一 tick 執行。
- 每位玩家各自 4 秒才能再下一次指令（`NPC_TALK_GAP`）。
- **戰場回報只送給「這場戰鬥裡、同陣營」的玩家**：敵方玩家看不到，同國但不在這場戰鬥的玩家也看不到（以前整個國家都會收到）。聊天每個接收者用自己的語言與編碼。
- 回報的限頻鍵包含戰場地圖，同國兩場戰鬥的回報互不壓掉。
