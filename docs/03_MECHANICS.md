# 03 现行游戏机制

代码：`sgserver.py` 的 `enter_field()`、`SHARED MAPS AND BATTLES`、`POC capture`、`SQUAD LOST`、`REINFORCEMENT SQUADS`、`BATTLE RESULT`、`BATTLE CONTROL`、`ALIEN *`、`progression.py`、`aliens.py`。

## 1. 进入地图 `enter_field(s, mapid, x, y, capital, watch, sim)`
送 0x17：`u32 map, u8 capital, u32 owner, u8 battle, u8, u32 start, u32 end, u8 kind, u8 THEME, u8 nObj, obj×{u32 id,u16 x,u16 y,u16 strength,u8 type,u32 owner}`。
- start/end 不能相等（客户端会除以 0）。战斗：start 1000、end = +30 分钟（`BATTLE_SECONDS`）。
- THEME 必须正确，否则地面马赛克（`map_terrain()`）；首都用 13。
- 依地图类型分支：

| 情况 | 结果 |
|---|---|
| 自己/同盟的省 | 城镇（不是战斗），NPC 指挥官在城里走动（`npc_town_sync`） |
| 他国的省 | **PvP 战斗**，无外星怪；NPC 守军（`npc_spawn_defenders`：已在省内的 4–10 s 后从星门进场，其他从所在地行军） |
| 中立省 | 外星怪驻军（`spawn_aliens_initial`），可能有 NPC 同时围攻（`npc_spawn_siege`） |
| 本国省被袭（RAIDS） | 防守外星怪 / NPC 的突袭 |
| 洞穴 1–3 | HIVE 模式：多波外星怪 + 孵化巢，全部摧毁即胜 |
| 模拟中心 `sim` | 不损失单位、不得经验（`BATTLE SIMULATION CENTER`） |
| 伏击省 `AMBUSH` | NPC 拦截战，**无 POC，全灭定胜负**；加入时聊天框提示 |

## 2. POC（占领点） [确认]
- 每张省份图的 POC 位置预先算好：`server/poc_spots.json`（`tools/gen_poc_spots.py`）。
- 强度 = 占领秒数 × `POC_RATE 100`（新手星 `POC_NOVICE_SECONDS`，其他依 POC 数）。
- **客户端模拟占领**（0048f340）：敌方单位站在上面每次更新 -5，<0 换主人。服务器以客户端 **0x5a 回报为准**（F9 0xF4 只是调试）。
- 攻方占领**全部** POC → 胜利；时间到 → 守方胜；攻方全部撤离 → 守方胜。
- 第三方（非攻非守）占领全部 POC → 战斗结束（`ghost_check_end`）。
- 能源板 / 甲烷口：type 6/7，放在同一个目标列表，但不计入 `s.pocs`。孵化巢标记：type 0、强度 0。

## 3. 部署、增援、重新部署 [确认]
- 每场可上阵单位 = `Tactics // 20 + 6`（`progression.py`）；装备不合法的单位无法部署（见 06）。
- **F7 增援**：客户端 0x19[00] → 服务器 class-B 0x50 `[u32 frame][PUT]` 发给所有参战者；冷却 `REINFORCE_COOLDOWN = 60 s`，出现延迟 `REINFORCE_DELAY = 300` 帧。
- **全灭 / 全部撤出** → 0x51 重新部署框（等待 20 s、选择 60 s）。客户端 0x53 = 用目前部队重新进场；无可用单位 → 中文提示「沒有可用單位，請先修理或補充」并判负。窗口超时：全灭 → 败；撤出 → 撤退。
- 离开战斗后 `REJOIN_WAIT = 30 s` 才能再进。

## 4. 撤退 [确认，2026-10-23 规则]
- 单位走到出口传送点 → 客户端 0x2f → 该单位个别撤出（`retreat()`，保留 HP）。
- 指挥官到达出口或按撤退（Ctrl+F11 / 菜单 → 0x54）→ 显示结算（RETREAT）后离开。
- **目的地** `retreat_target()`：来时的相邻省 > 己方/同盟相邻省（离首都近者）> 任一相邻省。目的地若已被截断（敌方占有/封锁），就要在那里**再打一场**；**只有全灭才直接飞回首都**。
- 落点 = 目标省面对战斗省的那个星门。
- 防卡死：撤退中旗标最多保留 `RESULT_SHOW_SECONDS + 15 s`；进入目标失败 → 改回首都。

## 5. 多人战斗与指挥官 [确认]
- `BATTLES[mapid] = B`：members、targets（服务器单位）、pocs、owner（战场指挥官）、defender、npc_side、ghost …
- **战场指挥官 = 参战玩家中军阶最高者**（`battle_best_commander`），加入 NPC 开启的战斗时自动指派。
- 加入：0x20 请求 → 指挥官同意（Ctrl+F7 模式 1 自动同意）。客户端只有在省份记录的国家清单含己方时才显示 JOIN；**三方战斗**时服务器把玩家国家加进清单。
- 与己方 NPC 友军并肩作战需要客户端 ≥ 1.0.11（`ALLY_CLIENT_RELEASE`），旧版客户端会把友军 NPC 单位撤掉以免崩溃。

## 5b. 战后离场（2026-10-23 21:47）
- 结算后，**不属于该省主人一方的玩家/NPC 都要离开**：
  - 胜利方只有在省份归自己/同盟时才留在原地；省份属于别国 → 送到相邻己方省份（否则首都）。失败 → 首都。
  - `evict_sweep()`（每 NPC tick）：任何玩家站在别国省份地图上、该省没有战斗、进来超过 15 s → `evict_province()` 移出并提示。
  - NPC：任务结束走回家时，若所在省属于别国，**第一步直接从邻省开始**（不在敌省停留）。
- 要再进去只能从相邻省重新开战。

## 6. 结算 0x25 [确认]
- 结果 0 胜 / 1 败 / 2 撤退；阵营信息（省数、阵营胜场、**本场对手 1 条**）；4 兵科 XP 动画；5 种资源；6 种加成；每个单位的 XP/击杀/可升级图示。
- 撤退：无战斗加成，非胜非败，不占领。

## 7. 成长（progression.py） [规则确认，XP 数值暂定]
- 4 兵科 INF/MOB/AVI/ORG，单位升级 → 兵科 XP → 兵科升级给 1 点属性。
- Tactics：上阵数；Clout：单位品质 UQ = 等级 + Clout/2、影响力；Education：科技等级 TL = 等级 + Education/2；Mech：载重 ×(1+mech/120)。
- 声望 PR：Elo/USCF 式（`PRESTIGE RATING`）；勋章 0x27（`MEDALS`）；转生 +2 单位上限。

## 8. 外星怪（aliens.py） [规则确认，数值暂定]
- 等级 = 星球级别基数 + 离最近首都的距离 + 狩猎场深度 ±2；新手星上限 = 参战者最高兵科等级。
- 中立省驻军 0–100 %：击杀降低，每小时恢复 +10 %；玩家中途加入多一队。
- 狩猎场：每 `WAVE_SECONDS` 一波，最后一波有 Boss。
- 反扑（RAIDS）：外星怪攻打强中立省旁的已占省，无人防守则失守。
- 空中外星怪（Oizys/Manta/Mamos）从进阶星开始出现。

## 9. 战略图
- 0x2b 开/刷新 → 0x2d（85 省、归属、指挥官位置、战斗标记）。0x2c → 0x2e 省份信息（预览小地图、USERS 清单、NPC 点）。

## 單位經驗值（2026-10-23 23:33 改為按傷害分配）
- 擊倒一個敵人總共值 KILL_XP(25) × 敵人等級；各單位依「造成的傷害 ÷ 敵人最大 HP」分得對應部分（note_damage_xp）。
- 擊殺者另外拿到伺服器沒看到的那部分傷害（kill_share）。所以一次擊殺的經驗總量和以前一樣。
- 傷害經驗在戰鬥結束時發放（pay_damage_xp）：勝利、失敗、撤退都發；也計入 xp_gain（勝利擊殺加成、結算加成）。
- 限制：只計伺服器看得到的傷害（攻擊命令 / 技能打外星怪和 NPC 單位）。單位自動開火、玩家對玩家的傷害由客戶端模擬，伺服器看不到。
- **（2026-10-24 20:13）撤退只能走非敵國的星門**：戰鬥中單位走到通往**敵國**省份的星門（客戶端 0x2f）→ 拒絕，單位留在戰場，提示改走通往己方 / 同盟 / 中立省份的星門。四周全是敵國時才允許撤退（直接回首都）。`battle_flow.retreat()`，test48 第 6–7 項。
- **（2026-10-24 20:18）戰場內 F7 重新選單位**：戰鬥中按 F7（冷卻時間已過，且有不在戰場上的活單位：從星門撤退的、預備隊）→ 開派兵視窗；按 OK 後，選進部隊（slot > 0）且不在戰場上的單位當作增援進場（最多補到部署上限）。冷卻中按 F7 → 顯示剩餘秒數。`battle_maps.reinforce / reinforce_chosen`，`F7_CHOOSE = False` 可改回舊的自動預備隊。test52。

## 2026-10-24 23:51–23:57 撤退後重新進場：雙生單位
- 現象：撤退換隊再進場後，圈選單位兩側沒有狀態；第二次全滅時按 F7 沒反應，只能等增援框時間到；每換一次隊遊戲越卡，NPC 漂移，視窗移動緩慢。

  - 每多一組雙生，模擬就多一份負擔，同步也跟著亂（NPC 漂移）。
- 修正：
  - `battle_maps.fresh_battle_uids`（`FRESH_REENTRY_IDS = True`）：已經在這張地圖上過場的單位，再進場前先換新編號，做法同 Lab 升級：客戶端收到 0x16 sub 3 移除舊號、sub 2 加入新號，再加上裝備。擊殺、經驗、HP 等戰鬥紀錄跟著搬到新號。
