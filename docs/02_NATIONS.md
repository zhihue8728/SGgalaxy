# 02 星系 / 国家框架

代码：`sgserver.py` 区段 `WORLD CONFIG`、`PROVINCE OWNERSHIP`、`NATIONAL POWER`、`TERRITORY / WAR TAB`、`URANIUM`、`STAR CENTER`、`REINCARNATION`；`npc.py`。

## 1. 星系与星球 [确认]
- 一台服务器 = 一个星系 8 颗星球（客户端 `vinu.inf`、`pam2.dat`）。开放 3 颗：

| 星球 id | 名称 | 级别 (PLANET_TIER) | 对新玩家开放 |
|---|---|---|---|
| 6 | Novice 新手星 | 1 | 是（`BEGINNER_PLANET`） |
| 2 | Advanced 进阶星 | 2 | 否，经 StarCenter 进入 |
| 3 | Elite 精英星 | 3 | 否 |

- 轨道向量不可为 (0,0,0)（客户端 0045a4e0 旋转后会落在恒星里，星球页全黑）。
- **所有星球都用 vinu 布局 2**（9×9 网格：偶数列行 0–8、奇数列行 0–9，共 85 省）。`LAYOUT = {p: 2}`，0x43 封包通知客户端。

## 2. 省份 id [确认]
- `province id = planet*100000 + col*100 + row`（CCRR）。例：600402 = 星球 6、第 4 列、第 2 行。
- **玩家看到的编号**：大地图在每省画「省份编号」01–85（`province_number()`，名称最后两个字元）。所有给玩家看的讯息都用这个编号（`province_label()` → `#41`，`province_label_lang()` → 「41号省」），**不要显示内部 id**。
- 战略图坐标：`_strat(p) = (c*0.866, r - 0.5*(c%2))`（六角网格）。
- 地图种类：`< 100000000` 省份；`2xxxxxxxx` CTF/训练；`4/5/6xxxxxxxx` 洞穴/狩猎场（`map_kind()`）。
- 省份图上的相对传送：±100 / ±1 = 相邻省，+10000..+80000 = mon1..mon8 狩猎场。

## 3. 国家 [确认格式 / 名称由使用者决定]
`NATION_DEFS = (id, 英文名, RGB, 星球, 角落槽 0..3)`，**id 存在帐号里，不可重编号**。

| 槽(颜色) | 新手星 6 | 进阶星 2 | 精英星 3 | 中文名 |
|---|---|---|---|---|
| 0 红 | 1 | 11 | 21 | 赤焰国 |
| 1 绿 | 2 | 12 | 22 | 翠林国 |
| 2 蓝 | 3 | 13 | 23 | 苍海国 |
| 3 黄 | 4 | 14 | 24 | 金阳国 |

- 进阶/精英加前缀「进阶」「精英」（`nation_name(nid, lang)`）。0 = 中立（外星怪）。
- **不用 id 5**：客户端星门距离检查对国家 5 特判（佣兵）。
- 首都 = 角落省：`CORNERS[p] = [p00000, p00800, p00008, p00808]`（左上、右上、左下、右下）。首都用 `Capital.nm` + 叠加层，0x17 的 CAPITAL 旗标 = 1。

## 4. 领土 [确认]
- 归属存在 `game.db` kv `"world"` 的 `owners`（旧版 `world.json`），首都永远属于自己国家。
- 改归属**只能**用 `set_province_owner(pid, nid)`：会写 `owner_log`（最多 5000 条，含调用函数名）、通知 NPC（`npc_owner_changed`），并在结算后执行 **`evict_province`**：不属于新主人一方的玩家被送到相邻己方省份（否则首都）。NPC 的撤离由 `npc_tick` 处理（见 04）。
- 省份「持有时间」`since` 用来计算地块价值。

## 5. 同盟与敌友 [确认]
- `NATION_ALLIES = [(a, b)]`，持久化在 world `"allies"`；`same_side(a, b)` = 相同或同盟。
- **NPC 外交**（2026-10-23）：同盟会依战略自动结成/解除，规则见 04_NPC_AI.md 第 E 节；有真人总统的国家不自动变更。
- 客户端敌友由 class-A **0x05** 决定（同盟 state 1 合并为同一组）。**不送 0x05 = 所有单位同组 = 全是友军**，服务器每次 0x0F 后都会送。
- `side_nation(s)` = 玩家实际作战的一方（佣兵为所服务的一方）。佣兵 = 客户端 0xd6。
- FHQ 选举/内政/外交（0x36 → 0x37）、`/ally` 结盟、总统/议会：见 `FHQ` 区段与 `research_social` 相关文档。

## 6. 国力、魔星、地块价值 [暂定数值]
- 每个占领省（不含首都）价值 = `FIELD_VALUE_BASE 10 + 每小时 +1`（上限 50）。
- **结算**：每个魔星窗口前 5 分钟（UTC+8，`STAR_WINDOWS` = 12:00、19:00），国力 += 地块价值 × 8。
- 国力满 `POWER_FULL = 40000`（2026-10-27 起；战略地图 WAR 页「整体战况」显示 国力/40000） → 24 小时魔星时间，四颗魔星（青龙/白虎/朱雀/玄武）各对应一类装备，只在窗口开放 1 小时。
- 战略图 WAR 页：显示占领省数 / 星球省数（客户端 00435030 只显示服务器给的数）。
- 收入：`PROVINCE INCOME CYCLE`（每 30 分钟，占领省 × 星球级别，占位值）；铀（Ura）规则见 `URANIUM` 区段。

## 7. 阵营战绩 [确认显示方式]
- `faction_record(nid)` = `{"w", "l", "vs": {对手国: [胜, 败]}}`（world `faction_record`）。
- 结算窗口 0x25 只送**本场对手国家 1 条**（`battle_enemy_nation()`），因为客户端面板只放得下 1 条；打外星怪送 0 条。客户端格式只显示「%d 胜」，败场不显示（原版行为）。

## 8. 国家规模平衡（NPC） [确认于 2026-10-23]
- 公平份额 `npc_fair = 星球省数 / 国家数`（新手星 ≈ 21）。
- 超过 `NPC_MAX_SHARE = 2.0` 倍：仍可进攻，但同时只开 1 场、只打其他国家；每次占领后的休整 `npc_gain_gap` 随规模平方增长。
- 刚失去领土的国家受保护 `PROTECT_SECONDS`；只剩 ≤ 3 省进入「最后防线」（单位 HP ×1.25、多 5 名 NPC，6 小时）。
