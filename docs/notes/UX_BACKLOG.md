# 體驗優化清單（伺服器與客戶端計算同步）

建立：2026-10-20。決定：先完成其他功能，最後再統一處理本清單。
目前狀態：伺服器負責外星怪的血量與死亡（`ALIEN_CLIENT_CONTROL = False`），客戶端使用原版 SG.exe（開火當下扣血）。

## 背景（反組譯已確認）
- 戰鬥是同步模擬：每個客戶端自己模擬所有單位（移動、尋路與碰撞、武器冷卻、扣血、範圍傷害），畫面上的血條來自客戶端自己的模擬。
- 伺服器只轉發命令，並為「沒有客戶端控制」的外星怪決定死亡（送 0x23）。
- 單位死亡由「控制方客戶端」回報：單位更新函式 004cc220 在血量歸零時送出 0x1e。控制方 = PUT 的擁有者名稱等於本機指揮官（單位 +0x69）。
- 客戶端事件佇列、血量、能量、動畫幀都有可回溯的歷史紀錄（004ca320），各客戶端結果一致。

## 待優化項目

### 1. 外星怪的血量與死亡時間和畫面不一致（優先）
- 現象：外星怪 0 血不死，或還有血就先倒下。
- 原因：伺服器自己估算的血量和客戶端畫面上的不同。伺服器不知道外星怪在客戶端的實際位置（範圍傷害打到幾隻）、實際開火時間與射程判斷；log 中伺服器估算與客戶端實際血量差到 200 以上。
- 方案 A（已試過，效果最好）：`ALIEN_CLIENT_CONTROL = True`，外星怪登記在開戰玩家名下，由他的客戶端在血量歸零時回報死亡，伺服器轉發；玩家對外星怪下的命令由伺服器丟棄；開戰者離開時用 class-B 0xcc 'fldcuo' 轉交控制權。
  - 待解決的副作用：外星怪出現在玩家的單位列表與側邊面板中（截圖「Ubik L1」），名字下方顯示玩家名稱。需要客戶端補丁把「名下但非本國」的單位從列表與選取中排除，或找出原版設計中專給 NPC 用的控制方式。
- 方案 B：伺服器完整重現模擬（尋路、碰撞、冷卻、射程）。工程量很大，難以做到完全一致，不建議。
- 可利用的資料：控制方客戶端每 5 秒回報 0x21 [uid][01][hp]（外星怪 HP），死亡後回報 0x2f [受害者][..][擊殺者]，可用於擊殺歸屬。

### 2. 攻擊動畫與扣血的時機（先看到動畫再扣血）
- 現象：第一下攻擊在動畫播完之前就扣血。
- 原因（原版行為）：普通攻擊 004e55b0 在冷卻到時的同一 tick 切換開火動作、立即扣血並在目標處產生命中特效；武器的槍口與飛彈畫面在動畫「命中格」才出現（004c6b60 判斷動畫幀旗標）。
- 方案：客戶端補丁，見 HIT_DELAY_PLAN.md（暫停中）。v1 固定延遲 D 已做（SG_hitdelay.exe，未啟用）；v2 構想是在動畫命中格才扣血（命中格屬於可回溯的模擬狀態，各客戶端一致），並讓沒有實際丟出的手榴彈不再出現爆炸畫面。
- 注意：所有玩家必須使用同一版客戶端。

### 3. 手榴彈：有爆炸畫面但沒扣血、能量沒扣
- 現象：連丟手榴彈時，約每兩顆有一顆在客戶端沒造成傷害（由 0x21 血量回報比對確認），畫面上仍有爆炸。
- 推測：單位停在丟擲動作上時，動作每循環一次就在命中格重播爆炸特效（4e6190 尾段：狀態 0x17 + 命中格 → 004ce0a0），但沒有真的丟出（冷卻或射程判斷沒過）。
- 伺服器的能量估算因此偏低，之後會把客戶端真的丟出的手榴彈判成「能量不足」。
- 方案：併入第 2 項的 v2 補丁；伺服器改用客戶端回報的資料校正能量與冷卻。

### 4. 伺服器的能量估算與客戶端不同
- 伺服器沒有模擬開關型技能的每秒耗能（隱形等）、移動耗能等，也不知道客戶端是否真的施放。
- 方案：以客戶端實際行為為準（例如控制方回報），或只用於記錄、不用來拒絕施放。

### 5. 技能的其他未確認項目
- IRBM 從發射到落地的延遲時間未量測（伺服器目前立即結算）。
- 地雷類技能（Mine / EMP Mine / Chemical Mine / Air Mine）伺服器未模擬。
- Fusion Storm、Earthquake 在客戶端的冷卻未確認。
- 技能的作用範圍：只確認了手榴彈 128、自爆 280、IRBM 210、地震為施放者視野。

### 6. 命令上傳延遲
- 客戶端約每 0.5 秒批次上傳命令，伺服器宣告死亡後還要等一個同步幀，死亡最多晚約 0.5 秒出現。
- 方案：確認客戶端的上傳間隔是否可由伺服器設定，或接受這個延遲。
