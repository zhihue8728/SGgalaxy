# Shattered Galaxy 1.8.5 私服 — 架構與遊戲機制總覽（2026-10-20）

本文件是「入口」：說明整體架構、已逆向的遊戲機制、伺服器怎麼實作、哪些數值是暫定。
封包逐欄位細節在 PROTOCOL.md；早期網路層/檔案格式在 FINDINGS.md；新手升星與教學在 progression_tutorial_notes.md。
標記：**[確認]** = 反編譯 + 遊戲內驗證；**[推測]** = 只有反編譯或推論；**[暫定]** = 我們自訂的設計值，可調。

## 1. 系統架構

| 部分 | 位置 | 說明 |
|---|---|---|
| 客戶端 | `C:\Program Files (x86)\KRU\Shattered Galaxy\SG.exe` 1.8.5 | 原版，不修改。所有遊戲資料檔（*.dat）在同目錄 |
| 伺服器 | `server/sgserver.py` | 單一 Python asyncio 程式：登入伺服器 + 世界伺服器（同一 port，0x03 轉址到自己） |

啟動：`python server\sgserver.py --port 3000`；日誌 `sgserver.log`。
封包：`0xAA + u16 長度 + 加密 payload`（FINDINGS.md §2）；伺服器→客戶端分 class-A（全域 handler）與 class-B（戰場/欄位 handler 004b5670）。

### 連線流程 [確認]
1. 0x00 握手（版本 0xB9）→ 0x0B 伺服器清單 0x46 → 0x03 轉址。
2. 0x05/0x0F 國家表 + 0x05 關係表 → 0x03 登入 → 0x02 ok + 0x0F(含 Neutral) + 0x05 + 0x06 + 0x15 指揮官 + 0x10 物品資料庫。
3. 第一個 0x58 心跳後：0x43 星球佈局表 → 0x17 進入首都 → 0x16 單位名冊 → 0x18/0x20 放英雄 → 0x0E 允許下令。

## 2. 世界結構

### 星系 / 星球 [確認]
- vinu.inf：1 個星系、8 顆星球（0..7），省份 id = 星球×100000 + 列×100 + 行。佈局表 0x43 讓所有星球共用 vinu 星球 2 的 9×9 格（85 省）。
- 星球記錄（0x40/0x38/0x31 共用）：u16 id, s8 名稱, u8 類別, u8 大小, u32 自轉角(1/1000°), 3×s8 傾角向量,
  **u16 A 半長軸, u16 B 半短軸**（焦距 √(A²−B²)，A≥B>0；0 = 位置無限遠）, **u32 軌道位置(1/1000°)**, u16, u8 旗標(+0x7c, 星門傳送需≠0), u8 OPEN。太陽大小 20 在原點。
- 伺服器設計 [暫定]：星球 6 = 新手星（開放新角色）、2 = 進階星、3 = 精英星（PLANETS / PLANET_TIER / PLANET_ORBIT）。

### 國家 [確認格式 / 暫定內容]
- 0x0F 國家表：id、名稱、可選旗標、顏色、首都(+0x110)、旗幟幀、戰況；之後是說明文字與省份擁有表。
- 群組表（FUN_005521d0）以「最大國家 id」為大小，id 可不連續；0x05 關係 state 1 = 同盟 → 同群組 = 友軍。
- **國家 5 在客戶端有特權**：星門距離檢查與 FHQ 進入檢查都跳過 5 → 不要給玩家用 5。
- 伺服器：新手星 1–4、進階星 11–14、精英星 21–24，首都在 9×9 格四角（x00000/x00800/x00008/x00808）。

### 地圖 id [確認]
| id | 地圖 |
|---|---|
| < 1e8，(id/10000)%10 = 0 | 省份地圖 `%08d.nm`（找不到時 `000`+末5碼） |
| 同上，1–8 | 怪物獵場 mon%d.nm |
| 同上，9 | 太空站 sst.nm |
| 2xxxxxxxx | CTF/訓練 exercise.nm |
| 4/5/6xxxxxxxx | 洞窟 Cave1 / rr1 / nbattle |
- 0x17 進入地圖：u32 地圖, u8 CAPITAL(1 = Capital.nm + 覆蓋層), **u32 地圖擁有國**（FHQ 權限與友方領土）, u8 戰鬥模式, … u8 地形主題(12/13，0 = 用 vinu 值)。
- 地形主題必須跟該圖相符，否則小地圖繪製崩潰在 SG.exe+0x8d533（0x2e 預覽也會用同一個載入器）。

## 3. 戰鬥 [確認]
- 戰場以 lock-step：伺服器每 ~0.1 s 送 0x80 lump（帶遊戲時間），客戶端模擬。
- 客戶端 lump：0x16 移動、0x18 位置回報、0x29 攻擊[uid][目標]、0x1e 死亡、0x21 HP 回報[uid][01][u16 hp]。
- 伺服器 lump：0x1a 移動、0x23 死亡[u32 uid]、0x2b 攻擊物件[攻擊者][目標]（外星 AI）、0x30 動作。
- PUT_UNIT 0x18：HP、能量、速度×10、視野、9×u16 戰鬥數值（護甲、護甲類別、傷害類型、地/空 傷害·射程×20·冷卻×100）、u64 能力位元（bit1 = 攻擊按鈕）。
- 伺服器：攻擊/死亡/殘骸、外星 AI 反擊、CTF 全滅自動結算；擊殺給 XP、資源（KILL_REWARD×等級）、prestige。

## 4. 單位 / 工廠 / 研究所 / 物品 [確認]
- 0x44 單位表、0x2f '@' 工廠、0x2d 買/賣/**修理（op 4 [u32 shop][04][u32 uid] → 0x2f 'B' [u32 uid][5×u32 修理費]）**。
- 0x16 名冊記錄：block A[0] 最大 HP、[1] 目前 HP、[4] 負重、[5] 空間、[7] 速度×10；u32 #1 最大負重。
- 0x33 研究所：升級樹（需求 UQ）、裝備物品清單；0x10 物品資料庫（科技等級、重量、空間、武器數值）。
- 修理費 = 價格 × 40% × 損傷比例 [暫定]。

## 5. 指揮官成長（F4）[公式來自使用者提供的規則；XP 數值暫定]
- 四兵科 INF/MOB/AVI/ORG；單位升級 → 兵科 XP → 兵科升級 → 1 屬性點（客戶端 0x25 分配）。
- Tactics：每場單位數 = Tactics/20 + 6；Clout：UQ = 單位等級 + Clout/2、影響力 = 兵科等級 + Clout/2；
  Education：TL = 單位等級 + Education/2；Mech：負重 × (1 + Mech/120)。
- 新手星兵科上限 35；任一兵科 ≥ 20 可到 StarCenter 宣誓前往進階星。
- F4 視窗 = 伺服器 0x27 sub 0：s8 稱號, u8, 4×{u8 等級, s8 軍階, u8, u8, u32 XP, u32 下一級總 XP}, u8 轉生次數,
  u32 prestige, u32 honor(顯示 /100), u32, u8 n {u32 勳章, s8}, u16 勝, u16 敗, u8×4 屬性, u16 點數, s8 上級, u8。
- Honor（顯示值 = 內部 /100）：勝利 省份 +5 / 獵場、洞窟 +1 / CTF +0.1，佔領 +10，擊殺 +0.1×敵等級，戰敗 −2；
  加入最強派系扣 50%。效果（客戶端說明 "extra health for every 100 honor"，數值由伺服器定）：每 2000 Honor +1% 最大 HP，
  上限 +50%（HONOR_PER_PCT / HONOR_HP_CAP；估算活躍玩家約 250 小時封頂）。PR = Elo（PR_START 1000，K 32）。
- 勳章【已在遊戲內確認 2026-10-20】：圖檔 dcr-%03d.xpf (id//1000)，frame = id & 31，group = (id%1000)>>5。
  每個 dcr 檔的 frame 0 是空的 → id 必須是 N*1000+f（f≥1）。共 198 張圖（約 156 種樣式），總覽 analysis/medals/medal_sheet.png。
  伺服器定義 12 種（MEDALS），舊的 N*1000 編號自動遷移；GM：/medal all|clear|KEY|id N…

## 12. 2026-10-20 新增系統（[暫定] 數值都在 sgserver.py 常數）
- **轉生**：精英星 + 任一兵科 ≥ 100+已轉生次數 → 星盟中心列出新手星國家（MODE 1）→ 選外觀 → 兵科歸 1、轉生次數 +1、
  單位上限 +2、送外星單位、回新手星；最多 10 次。四項屬性、未用點數、榮譽、PR、勳章、資源、單位全部保留（使用者決定 2026-10-20）。0x15[0x47d]、0x20 rank byte、F4 顯示次數。
- **榮譽**：內部單位 = 顯示 ×100。勝利 省份 5 / 獵場·洞窟 1 / CTF 0.1，佔領 +10，擊殺 +0.1×等級，戰敗 −2。
  效果：每 2000 顯示榮譽單位最大 HP +1%（上限 50%，HONOR_PER_PCT）。加入最強國家（PENALTY）損失 50% 榮譽與鈾。
- **勳章**：12 種（首殺、百殺、首次佔領、10 省、無損勝利、進階、精英、轉生、1000 榮譽、10 洞窟、50 POC、兵科 100）。
- **單位技能**【確認 2026-10-20】：裝備 Special → 能力位元；PUT_UNIT +0x2a 技能表 {u8 位元, u16 耗能, u16 威力}
  = 裝備的 Energy Use / Effectiveness（原版資料）；開關型技能耗能為每秒。PUT +8 每秒能量變化 = 裝備 Energy Drain 總和
  （只有 Fallout 反應爐回能）。0x30 動作 → 位元對照、各技能原版公式見 research_skills.md §5；伺服器對外星生物模擬
  手榴彈（目標全額、128px 內半額）、地震（施放者視野內）、自爆（280px）、IRBM（210px）、核融合風暴（目標最大 HP %）。
  Heal 只對生物、Repair 對機械。偽裝中不能佔 POC。已確認：隱形。
- **F8 回首都**【確認】：F8（或「這裡沒有商店/研究所，回首都？」）→ 客戶端 0x3a [00] → 伺服器傳送到首都（戰鬥中拒絕）。
- **戰場控制**：Ctrl+F11 強制撤退、單位各自走撤退門、戰鬥 30 分鐘時間到防守方勝。
- **多人戰鬥**：同地圖互相可見；第二位玩家進入戰鬥需指揮官許可（15 秒無回應自動同意）；共用時鐘/外星生物/POC；
  指令轉發給所有參戰者；離開時通知其他人；全部 POC 由同陣營佔下 → 同陣營都勝利。
- **多人驗證**：`tools/mptest` 模擬客戶端（test1–7）涵蓋加入/觀戰/撤退/斷線/F7/有主人省份/傭兵；有主人的省份沒有外星怪、通知守方、守方靠時間或攻方全退獲勝；指揮官離開時指揮權交給同陣營的戰鬥者（不給觀戰者）。
- **增援（F7）**：超過出戰上限的單位留作預備隊；有空位且冷卻（60 秒）到時按 F7，下一批以 0x50 延遲放置同時出現在所有人畫面；
  否則顯示「幾秒後可增援」。
- **爭奪省份對話框**：走進正在交戰的省份會跳出 0x1e（ATTACK/ASSIST），選擇後再經指揮官許可加入。
- **觀戰**：大地圖選觀戰（0x20 type 13）→ 進入戰場但沒有單位，不計勝敗，戰鬥結束回首都。
- **傭兵**：指揮官視窗切換傭兵（0xd6）；傭兵可對任何戰鬥提供服務（0x20 type 4）並替該方作戰、佔領算該方，勝利多 20% 資源。
- 實驗性：中途加入的原版快照（0x0E[06] → 0x1d → 0x22）預設關閉（SNAPSHOT_RELAY），目前用重新放置單位的方式同步。

- **PR（Prestige Rating）**：Elo 式，起始 1000、K=32；對手 = 敵方玩家平均 PR，或 800 + 25 × 外星生物平均等級；撤退/觀戰不計。
