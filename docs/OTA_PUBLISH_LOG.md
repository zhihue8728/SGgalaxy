## 重新取回所有版本的说明（PowerShell，在 repo 资料夹）
```
ssh -i $HOME\.ssh\game.pem ubuntu@43.135.15.91 'cd /opt/sgserver/updates && sudo tar czf /tmp/relnotes.tgz versions/*/release.json && sudo chmod 644 /tmp/relnotes.tgz'
scp -i $HOME\.ssh\game.pem ubuntu@43.135.15.91:/tmp/relnotes.tgz out\ota\
```
（不要用 ssh 直接把内容输出到档案：中文 PowerShell 会把 UTF-8 当 GBK 转一次，中文变乱码。）
